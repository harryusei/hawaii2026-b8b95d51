# ハワイ新婚旅行・5日目

## 2026年10月17日（土）｜ワイキキビーチ・自由時間・最後のディナー

※すべてハワイ現地時間。\
※旅行最終盤のため、予定を詰め込みすぎず、海とホテルでのんびり過ごす日。\
※前日までの天候や観光状況に応じて、柔軟に変更可能。

## スケジュール

| 時刻         | 予定                   | 補足                                                               |
| ------------ | ---------------------- | ------------------------------------------------------------------ |
| 8:00〜9:30   | 朝食・カフェ           | ワイキキ周辺で、気になっていたお店やお気に入りのお店へ             |
| 9:30〜11:30  | ワイキキビーチで海水浴 | シェラトンから徒歩でアクセス。泳いだり、ビーチでのんびり過ごしたり |
| 11:30〜13:00 | 昼食                   | 食べ逃したハワイグルメなどを自由に選択                             |
| 13:00〜16:30 | 自由時間               | ホテルのプール、昼寝、ショッピング、お土産の買い足しなど           |
| 16:30〜17:30 | ホテルで休憩・着替え   | ディナーに備えてゆっくり準備                                       |
| 17:30〜19:30 | 新婚旅行最後のディナー | 第一候補：House Without A Key（ハレクラニ）                        |
| 20:00〜      | ホテル帰着・帰国準備   | 荷造り、購入品の整理、翌日の出発準備                               |

## ディナー候補

- **House Without A Key（ハレクラニ）**：第一候補。海沿いの開放的な雰囲気で、夕暮れとハワイアンミュージック、フラを楽しむ。
- **Azure（ロイヤルハワイアン）**：より特別感のある、高級シーフードディナー。
- **RumFire（シェラトン・ワイキキ）**：ホテル内で気軽に楽しめるオーシャンフロントのレストラン。

※日没は18:05〜18:10頃が目安。夕暮れを楽しむなら17:30前後のディナー開始が理想。

## オプション・代替案

- **シュノーケリング**：海のアクティビティを追加したい場合の候補。午前中の海水浴と入れ替えて検討。
- **サンセットクルーズ**：海上からワイキキやダイヤモンドヘッドを眺める体験。参加する場合はディナーを遅めに変更。
- **お土産の買い足し**：2日目のアラモアナで買い切れなかったものを、ワイキキ周辺で購入。
- **やり残した観光の回収**：天候や予約の都合で実施できなかったアクティビティがあれば、5日目を予備日として活用。

## この日の方針

- 基本はワイキキ周辺で過ごし、長距離移動はしない。
- 海水浴とホテルでの休息を中心に、予定を詰め込まない。
- ディナーだけは事前に予約し、新婚旅行最後の夜を楽しむ。
- 翌日の帰国に備え、夜更かしせず荷造りを済ませる。
